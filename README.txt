Before setting up, have Node.js installed (ver14 or higher)

Check installation and version via
node --version
npm --version

#1 Download the Project and extract to local storage
#2 Open folder "backend" in Terminal/Powershell
#3 npm install
   npm start
//should see Server running on http://localhost:5000//
#4 Open folder "frontend" in Terminal/Powershell (do not close prior terminal session)
#5 npm install
   npm start
//that should open the page on your most recent browser, if the system is running properly, i hope//
